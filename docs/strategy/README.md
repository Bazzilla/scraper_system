# Strategia di riferimento

Questa cartella contiene **copia** dei file strategici che guidano il progetto
(regole buy-the-dip, matrice Rischio/Opportunità, indicatori F1/F3/H5).

- `strategia_trading.md` — il prompt operativo originale (Regola 0-4, casi storici, formato report)
- `specifiche_strategia.md` — il "contratto" cristallizzato (51 specifiche A-K)

## Perché questa copia nel progetto

I file strategici originali vivono fuori dal repo (in una cartella personale
dell'autore). Sono stati copiati qui in `docs/strategy/` così il progetto è
**autonomo e riproducibile**: chiunque cloni il repo ha il riferimento
normativo senza dipendere da percorsi esterni.

## Regola

- **Fonte di verità**: i file qui sono la copia di riferimento per il codice
  e i context del progetto. Ogni modifica alla strategia va allineata sia qui
  sia (se necessario) alla fonte originale.
- **Nessun riferimento personale**: i file non contengono riferimenti a
  utenti, macchine o ambienti specifici.
